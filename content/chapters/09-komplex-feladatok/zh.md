# 综合练习

## 家用电器 {#haztartasi-gepek}

:::exercise

请使用 Java 语言编写一个应用程序，用于保存家用电器的信息、确定每台电器的能效等级，并管理一家家电商店的库存。在程序中，`家用电器` 类表示一般的家用电器，由它派生的 `洗衣机` 类表示洗衣机，而容器类 `家电商店` 则用于管理电器对象的集合。

本题附带 [**machines_input_zh.csv** 示例文件](content/chapters/09-komplex-feladatok/media/machines_input_zh.csv)，其中的数据来自 2014—2024 年。凡涉及电器使用年限和生产年份的计算，**一律以 2024 年为基准年份**，从而保证无论何时完成本题，结果都可以按照相同标准进行检查。读取 CSV 文件时，也可以使用提供的 [**CsvInput.java** 文件读取辅助代码](content/chapters/09-komplex-feladatok/media/CsvInput.java)。

### 家用电器类 {#haztartasi-gep}

创建一个名为 `家用电器` 的类，并实现以下字段、访问方法和操作。所有字段都必须声明为 `private`，只能通过指定的 getter 和 setter 方法访问。如果准备写入的值不符合要求，则必须抛出 `IllegalArgumentException` 异常，拒绝该修改。

**字段及访问要求**

- **编码（`编码`）**：`String` 类型的字段，创建对象后不允许从类外修改，因此只提供公有的 `获取编码()` getter。编码不能为 `null` 或空字符串，长度最多为 13 个字符，只能包含英文字母表中的大写字母、数字和连字符。第一个字符必须是大写字母，最后一个字符必须是大写字母或数字，并且不能出现连续两个连字符。
- **生产年份（`生产年份`）**：整数，必须位于 `[2014; 2024]` 区间内。该值不能从类外修改，只能通过 `获取生产年份()` getter 查询。
- **是否为小家电（`是否小家电`）**：布尔类型字段，创建对象时确定其值，之后不能修改。使用 `是小家电()` 方法查询该值。
- **耗电量（`耗电量`）**：`double` 类型，取值范围为 `[0.2; 2.5]`。实现公有方法 `获取耗电量()` 和 `protected` 方法 `设置耗电量(double 值)`。setter 必须先检查新值，只有验证通过后才能修改字段。类外不能直接改变耗电量。

**构造方法**

- `家用电器(String 编码, int 生产年份, boolean 是否小家电, double 耗电量)` 构造方法接收全部四项数据，检查其有效性后保存。
- `家用电器(String 编码, boolean 是否小家电, double 耗电量)` 构造方法必须调用前一个构造方法，并自动将生产年份设置为 `2024`。

**方法**

- **`计算能效等级(): int`**：无参数方法，根据电器的耗电量确定能效等级，具体对应关系如下。如果截至 2024 年，电器的生产时间已经超过五年，则计算结果降低一个等级，即等级数值增加 `1`，但最终数值不能超过 `5`。

- `[0.2; 0.6)` kWh：**1 级**；`[0.6; 1)` kWh：**2 级**；`[1; 1.5)` kWh：**3 级**；`[1.5; 2)` kWh：**4 级**；`[2; 2.5]` kWh：**5 级**。

- **`toString(): String`**：重写从 `Object` 类继承的方法，使返回的字符串包含电器编码、生产年份、属于小家电还是大家电、耗电量以及计算得到的能效等级。
- **`equals(Object 其他对象): boolean`**：如果两台家用电器的编码相同，则认为它们是相同的电器，而不考虑其具体属于哪种电器类型。参数为 `null` 或者不是相关电器类型时，方法应返回 `false`。
- **`hashCode(): int`**：重写该方法，并根据电器编码计算哈希值。必须保证被 `equals()` 判定为相等的电器具有相同的哈希值。

### 洗衣机类 {#mosogep}

创建一个名为 `洗衣机` 的类，继承 `家用电器` 类。洗衣机具有父类的全部数据，但始终属于大家电。新增字段必须声明为 `private`，并通过对应的公有 getter 和 setter 方法提供访问。

**字段及访问要求**

- **最低水温（`最低水温`）**：整数，只能取 `20`、`25`、`30`、`35` 或 `40`。实现 `获取最低水温()` getter 和 `设置最低水温(int 值)` setter；输入不合法时，setter 必须抛出异常。
- **每次洗涤用水量（`单次用水量`）**：`double` 类型，必须位于 `[4; 6]` 区间内。通过 `获取单次用水量()` 和 `设置单次用水量(double 值)` 访问此字段，setter 必须按照指定区间进行验证。
- **颜色（`颜色`）**：枚举类型 `颜色` 的字段，可取 `白色`、`黑色` 和 `不锈钢` 三个枚举值。实现 `获取颜色()` 和 `设置颜色(颜色 值)` 方法，不允许传入 `null`。

**构造方法**

- `洗衣机(String 编码, int 生产年份, double 耗电量, int 最低水温, double 单次用水量, 颜色 颜色值)` 构造方法接收全部必要数据，调用父类相应的构造方法并将 `是否小家电` 设置为 `false`，然后检查并保存洗衣机特有的字段。
- `洗衣机(String 编码, int 生产年份, double 耗电量, int 最低水温, double 单次用水量)` 构造方法通过调用前一个构造方法完成初始化，并自动将颜色设为 `白色`。

**方法**

- **`设置耗电量(double 值): void`**：重写父类中 `protected` 的 setter。对洗衣机而言，耗电量只能位于 `[0.5; 1.5]` 区间内；如果新值合法，则调用父类的 setter 保存。构造方法接收的耗电量也必须满足这一更严格的限制。父类构造方法负责进行一般性验证，而洗衣机构造方法还必须执行额外的严格检查。
- **`计算能效等级(): int`**：重写父类方法。首先计算 `k = 耗电量 · 最低水温 · 单次用水量`，然后按照下列区间确定能效等级。洗衣机必须采用这套单独的计算规则，不再根据生产年份进一步降低其能效等级。

- `[40; 75)`：**1 级**；`[75; 135)`：**2 级**；`[135; 210)`：**3 级**；`[210; 280)`：**4 级**；`[280; 360]`：**5 级**。

- **`toString(): String`**：重写字符串表示方法，使其在父类数据之外，还显示最低水温、每次洗涤用水量、颜色及洗衣机计算出的能效等级。生成继承数据的文字描述时，可以调用父类的 `toString()` 方法。

### 家电商店类 {#haztartasi-bolt}

创建一个名为 `家电商店` 的容器类，用于管理家用电器。内部集合不得从类外直接访问，因为电器的添加和查询只能通过该类提供的公有方法完成。

**字段、构造方法和访问要求**

- **电器集合（`电器列表`）**：`private List<家用电器>` 类型的列表。在类的构造方法中创建空列表，不得编写直接返回内部列表的 getter，也不得为该列表提供 setter。
- **商店名称（`名称`）**：`String` 类型字段。提供公有的 `获取名称()` 和 `设置名称(String 值)` 方法；对设置的字符串无需再进行额外验证。
- **`家电商店(String 名称)`**：构造方法创建空列表，并设置商店名称。

**方法和查询**

- **`添加电器(家用电器 电器): void`**：只有当传入的对象不为 `null`，并且列表中不存在编码相同的电器时，才将其加入集合。否则抛出 `IllegalArgumentException` 异常。判断重复时必须使用已经实现的 `equals()` 方法。
- **`获取较旧电器(): List<家用电器>`**：创建并返回一个新列表，其中只包含 2019 年以前生产的电器。修改返回的列表不能影响商店的内部列表。
- **`按能效等级查找洗衣机(int 能效等级): List<洗衣机>`**：新建一个列表，收集所有能效等级与参数相同的洗衣机。参数只能是 `1` 至 `5` 之间的整数，否则必须抛出异常。查询时检查每台电器的实际类型，并在必要时进行类型转换。
- **`按编码查找电器(String 编码): 家用电器`**：查找编码与参数相同的家用电器，并返回找到的对象。如果不存在对应编码的电器，则返回 `null`。该方法用于替代 C# 中可使用字符串作为键的索引器属性。

### 主程序 {#foprogram}

创建一个 `家电商店` 对象，并为商店设置任意名称。读取随题附带、以分号分隔字段的 `machines_input_zh.csv` 文件，根据每一行的数据创建 `家用电器` 或 `洗衣机` 对象，然后将其加入商店。程序最后显示两个筛选方法的结果，并测试按照电器编码进行查找的功能。显示结果时应使用各电器的 `toString()` 方法。

示例文件每行的第一个字段表示电器类型。以 `H` 标记的记录，其余字段依次为：编码、生产年份、`小家电` 或 `大家电`标记，以及耗电量。以 `M` 标记的记录，其余字段依次为：编码、生产年份、耗电量、最低水温、每次洗涤用水量和颜色。文件中的颜色使用 `白色`、`黑色` 和 `不锈钢` 表示，程序应将它们转换为 `颜色` 枚举中相应的值。数字使用小数点作为小数分隔符。

```text
H;ZEH-ITTW2Y82;2022;小家电;0.8
M;G3F72DF0EJ88;2019;0.9;40;5.3;白色
```
